解送人犯法定障礙事由計算機 （憲兵版）操作說明
設計：臺北憲兵隊 調查官吳鋐峮
發布日期：2026年05月

一、 軟體簡介
本工具專為憲兵偵防人員設計，依據《刑事訴訟法》第93條之1規定，協助精確計算移送地檢署的法定時限。系統會根據案件類別自動設定基準時限（一般案件 16 小時、通緝犯 24 小時），並自動扣除各項法定障礙時間。

主要特色
自動化氣象連線： 選擇所屬憲兵隊後，系統自動連線中央氣象署取得日出日落時間。

離線備援方案： 若無網路，自動改用 NOAA 演算法推算天文日出日落，不影響任務執行。

整合文書產出： 一鍵產出拘提逮捕告知書、詢前告知書及提審告知書（.docx 格式）。

隱私與安全： 所有計算與資料填寫均在本地端（您的裝置）完成，個資絕不上傳雲端。

二、 操作步驟
步驟一：填寫案件基本資料
案由： 輸入犯罪案由（如：詐欺、毒品、違反陸海空軍刑法）。

是否為通緝犯： 勾選後系統會自動切換基準時限（否：16H / 是：24H）。

嫌疑人資訊： 填寫姓名、性別、出生年月日、身分證字號及住居所。

承辦人資訊： 輸入級職與姓名（如：憲兵上士 吳鋐峮）。

單位選擇（關鍵）：

先選擇所屬指揮部（如：憲兵第202指揮部）。

再選擇所屬憲兵隊（如：臺北憲兵隊）。

系統會自動帶入隊址，並依此查詢當地的日出日落時間。

步驟二：確認日出日落時間

🟠 橘色訊息： 表示目前為離線狀態，系統已採演算法推算，或可手動修正。

步驟三：設定拘提 / 逮捕時間與地點
點選拘提 / 逮捕時間（預設為當前系統時間）。

輸入拘提 / 逮捕地點。

步驟四：新增法定障礙事由
點擊「＋ 新增事由」按鈕，選擇適用的障礙類型（如：夜間停止訊問、等候辯護人等）：

智慧填入： 若選擇「第3項：夜間停止訊問」，系統會自動將結束時間設定為「隔日日出」。

自動統計： 每新增一項事由，畫面下方會即時更新「障礙事由總計時數」。

步驟五：查看結果與產出報表
最終解送期限： 系統會自動計算（拘捕時間 ＋ 基準時數 ＋ 障礙總時數）。

匯出記錄表： 點擊「📋 匯出 法定障礙事由記錄表」，可下載符合書面格式的 .txt 檔案。

產出公文書表： 點擊頁面頂端的按鈕（如：告知本人通知書），系統將自動填入資料並下載 Word 檔。

三、 注意事項
暫存特性： 本網頁不具備資料庫功能，關閉視窗後資料即清除，請務必及時匯出。

實務判斷： 日出日落時間僅供參考，實務執行仍應依現場實際天色或法院見解調整。

編碼說明： 匯出的文字檔採 UTF-8（含BOM）編碼，使用 Windows 記事本或 Word 開啟皆不會亂碼。
